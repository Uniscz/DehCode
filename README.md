# DehCode

FREE-FIRST local runtime and router for open-source AI video models.

## Status
Initial architecture in development. No video generation or hardware compatibility has been validated yet. No paid API is required. Hardware, electricity, storage and internet are not free.

## Goal
Detect hardware, recommend realistic configurations, manage model downloads and execute video generation through modular adapters and runtimes.

## License
MIT for DehCode code: simple reuse and contribution, including commercial use. Model weights retain their own upstream licenses.

## Development sequence
Architecture → hardware detection → declarative registry → recommendations → first real adapter → installation → GPU generation validation → second adapter → local UI → optional ComfyUI.
